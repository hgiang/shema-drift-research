# New Block Kit blocks and Streaming API method updates

April 16, 2026

The following new blocks are now available for Block Kit use:

*   [Alert block](https://docs.slack.dev/reference/block-kit/blocks/alert-block.md)
*   [Card block](https://docs.slack.dev/reference/block-kit/blocks/card-block.md)
*   [Carousel block](https://docs.slack.dev/reference/block-kit/blocks/carousel-block.md)

In addition, we've made some updates to the text-streaming API methods to support streaming blocks:

*   [`chat.startStream`](https://docs.slack.dev/reference/methods/chat.startstream.md)
*   [`chat.appendStream`](https://docs.slack.dev/reference/methods/chat.appendstream.md)
*   [`chat.stopStream`](https://docs.slack.dev/reference/methods/chat.stopstream.md)

For more details about building with Block Kit, check out our [Block Kit overview](https://docs.slack.dev/block-kit.md)!
