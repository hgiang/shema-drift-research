# Release: Deno Slack SDK v2.9.0

April 1, 2024

In the Deno Slack SDK `v2.9.0` release, the [`invite_user_to_channel`](https://docs.slack.dev/tools/deno-slack-sdk/reference/slack-functions/invite_user_to_channel.md) built-in function makes the `user_ids` parameter optional rather than required. In addition, a `usergroup_ids` parameter was added, allowing you to invite entire user groups.
