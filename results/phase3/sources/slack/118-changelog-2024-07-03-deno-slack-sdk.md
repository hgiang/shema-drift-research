# Release: Deno Slack SDK v2.13.0 & v2.14.0

July 3, 2024

In the Deno Slack SDK `2.13.0` and `2.14.0` releases, we've added API methods to support Slack canvas and Slack Connect. See the Deno Slack API [`2.5.0`](https://docs.slack.dev/changelog/2024/06/14/deno-slack-api.md), [`2.6.0`](https://docs.slack.dev/changelog/2024/06/18/deno-slack-api.md), and [`2.7.0`](https://docs.slack.dev/changelog/2024/07/02/deno-slack-api.md) updates for more details.
