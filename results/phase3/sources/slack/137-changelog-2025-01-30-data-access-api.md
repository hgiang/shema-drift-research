# The Data Access API is here!

January 30, 2025

This API is now available in a limited release for interested partners. Use the [Data Access API](https://docs.slack.dev/apis/web-api/real-time-search-api.md) within apps that have the Agents & AI Apps feature enabled to access all the relevant Slack data you need to ensure a pleasant user experience for AI-enabled apps
