# Release: Deno Slack SDK v2.12.0

June 10, 2024

In the Deno Slack SDK `2.12.0` release, we've added the [`add_bookmark`](https://docs.slack.dev/tools/deno-slack-sdk/reference/slack-functions/add_bookmark.md) Slack function and the [`team_id`](https://docs.slack.dev/reference/types/team_id-type.md) type. In addition, you can now pass the optional `team_id` parameter to the [`create_channel`](https://docs.slack.dev/tools/deno-slack-sdk/reference/slack-functions/create_channel.md) and [`create_usergroup`](https://docs.slack.dev/tools/deno-slack-sdk/reference/slack-functions/create_usergroup.md) Slack functions.
