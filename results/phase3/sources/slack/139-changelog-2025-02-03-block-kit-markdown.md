# A new Block Kit block is now available for use!

February 3, 2025

The [markdown block](https://docs.slack.dev/reference/block-kit/blocks/markdown-block.md) for [Block Kit](https://docs.slack.dev/block-kit.md) accepts standard markdown and outputs formatted Slack markdown; intended for use in [apps that use platform AI features](https://docs.slack.dev/ai/developing-agents.md).
