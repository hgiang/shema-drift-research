# Deprecates the bank_transfer_payments capability type in favour of newer capability types

## What’s new

Deprecates the `bank_transfer_payments` capability type in favour of newer capability types per buyer’s location in the Capabilities API. The newer capability types are:

- `gb_bank_transfer_payments` for UK Bank Transfers (GBP customer balance payments)
- `jp_bank_transfer_payments` for JP Bank Transfers (JPY customer balance payments)
- `mx_bank_transfer_payments` for MX Bank Transfers (MXN customer balance payments)
- `sepa_bank_transfer_payments` for SEPA Bank Transfers (EUR customer balance payments)
- `us_bank_transfer_payments` for USD Bank Transfers (USD customer balance payments)

## Impact

Deprecates the `bank_transfer_payments` capability type in favour of newer capability types per buyer’s location in the Capabilities API. This gives you more specific, location-based capabilities.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2024-06-20`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
