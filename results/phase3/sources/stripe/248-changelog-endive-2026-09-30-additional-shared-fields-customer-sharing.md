# Adds additional shared fields to customer sharing

## What’s new

[Customer and Payment Method Sharing](https://docs.stripe.com/get-started/account/orgs/sharing/customers-payment-methods.md) now shares and synchronises the following [Customer](https://docs.stripe.com/api/customers.md?api-version=2026-09-30.endive) fields across accounts in a sharing group:

- [description](https://docs.stripe.com/api/customers.md?api-version=2026-09-30.endive#customer_object-description)
- [tax_ids](https://docs.stripe.com/api/customers.md?api-version=2026-09-30.endive#customer_object-description)
- [preferred_locales](https://docs.stripe.com/api/customers.md?api-version=2026-09-30.endive#customer_object-preferred_locales)
- [metadata](https://docs.stripe.com/api/customers.md?api-version=2026-09-30.endive#customer_object-metadata)
- [business_name](https://docs.stripe.com/api/customers.md?api-version=2026-09-30.endive#customer_object-business_name)
- [shipping](https://docs.stripe.com/api/customers.md?api-version=2026-09-30.endive#customer_object-shipping)
- [tax_exempt](https://docs.stripe.com/api/customers.md?api-version=2026-09-30.endive#customer_object-tax_exempt)
- [invoice_prefix](https://docs.stripe.com/api/customers.md?api-version=2026-09-30.endive#customer_object-invoice_prefix)

## Impact

You can update these fields on a customer from any account in the sharing group. Stripe automatically applies the changes across the group, reducing duplicate updates and keeping customer information consistent between accounts.

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2026-09-30.endive`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).
