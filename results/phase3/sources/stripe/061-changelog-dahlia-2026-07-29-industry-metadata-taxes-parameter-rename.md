# Renames the taxes parameter to tax items in industry metadata payment details

## What’s new

Renames the [taxes](https://docs.stripe.com/api/payment_intents/create.md?api-version=2026-06-24.preview#create_payment_intent-payment_details-car_rental_data-total-tax-taxes) parameter to [tax_items](https://docs.stripe.com/api/payment_intents/create.md?api-version=2026-07-29.preview#create_payment_intent-payment_details-car_rental_data-total-tax-tax_items) within the [total.tax](https://docs.stripe.com/api/payment_intents/create.md?api-version=2026-07-29.preview#create_payment_intent-payment_details-car_rental_data-total-tax) hash for car rental, lodging and flight payment details. This affects the [payment_details](https://docs.stripe.com/api/payment_intents/create.md?api-version=2026-07-29.preview#create_payment_intent-payment_details) parameter when you [create](https://docs.stripe.com/api/payment_intents/create.md?api-version=2026-07-29.preview), [update](https://docs.stripe.com/api/payment_intents/update.md?api-version=2026-07-29.preview), [confirm](https://docs.stripe.com/api/payment_intents/confirm.md?api-version=2026-07-29.preview) or [capture](https://docs.stripe.com/api/payment_intents/capture.md?api-version=2026-07-29.preview) a PaymentIntent, and when you [update](https://docs.stripe.com/api/charges/update.md?api-version=2026-07-29.preview) or [capture](https://docs.stripe.com/api/charges/capture.md?api-version=2026-07-29.preview) a Charge.

The renamed parameter applies to all three industry verticals:

- [payment_details.car_rental_data.total.tax.tax_items](https://docs.stripe.com/api/payment_intents/create.md?api-version=2026-07-29.preview#create_payment_intent-payment_details-car_rental_data-total-tax-tax_items)
- [payment_details.lodging_data.total.tax.tax_items](https://docs.stripe.com/api/payment_intents/create.md?api-version=2026-07-29.preview#create_payment_intent-payment_details-lodging_data-total-tax-tax_items)
- [payment_details.flight_data.total.tax.tax_items](https://docs.stripe.com/api/payment_intents/create.md?api-version=2026-07-29.preview#create_payment_intent-payment_details-flight_data-total-tax-tax_items)

Previously, on older API versions, requests using `taxes` were automatically converted to `tax_items` and responses returned `taxes` for backward compatibility.

## Why is this a breaking change?

Previously, the parameter was named `taxes` within the `total.tax` hash. On `2026-07-29.preview` and newer versions, the API no longer accepts `taxes` and returns a `parameter_unknown` error. You must update any requests that set `total.tax.taxes` to use `total.tax.tax_items` instead.

## Impact

You can no longer use `taxes` in the `total.tax` hash on `2026-07-29.preview` or newer – sending it returns a `parameter_unknown` error. Update your code to use [tax_items](https://docs.stripe.com/api/payment_intents/create.md?api-version=2026-07-29.preview#create_payment_intent-payment_details-car_rental_data-total-tax-tax_items) instead. To update your integration, see [Industry metadata](https://docs.stripe.com/industry-metadata.md).
