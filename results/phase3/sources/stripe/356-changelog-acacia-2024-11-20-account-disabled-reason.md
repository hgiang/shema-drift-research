# Converts properties on the Account object from a String to an enum

## What’s new

The following [Account](https://docs.stripe.com/api/accounts.md?api-version=2024-11-20.acacia) properties now use an enum value instead of a String:

- [requirements.disabled_reason](https://docs.stripe.com/api/accounts/object.md?api-version=2024-11-20.acacia#account_object-requirements-disabled_reason)
- [future_requirements.disabled_reason](https://docs.stripe.com/api/accounts/object.md?api-version=2024-11-20.acacia#account_object-future_requirements-disabled_reason)

## Impact

When Stripe disables an account, the reason is now based on a finite set of enums rather than a String value. This change doesn’t add any new disabled reasons.
