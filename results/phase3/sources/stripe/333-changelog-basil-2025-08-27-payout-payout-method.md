# Makes the payout_method field a required property on the Payout object

## What’s new

The `payout_method` field is now returned as part of the `Payout` object.

## Impact

The `payout_method` field is now returned as part of the `Payout` object. When set, this ID indicates the v2 Financial Account that received the payout.

## Changes

#### REST API

| Field | Change | From → to |
| --- | --- | --- |
| `Payout.payout_method` | Changed | `optional → required` |
