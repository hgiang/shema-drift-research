# Replaces Upcoming Invoice API methods with the Create Preview Invoice API

## What’s new

We’re removing the `GET /v1/invoices/upcoming` API in favour of the [Create Preview Invoice API](https://docs.stripe.com/api/invoices/create_preview.md?api-version=2025-03-31.basil).

Additionally, you can no longer preview the next invoice for a customer across all their subscriptions on the [Create Preview Invoice API](https://docs.stripe.com/api/invoices/create_preview.md?api-version=2025-03-31.basil).

## Why is this a breaking change?

- The Upcoming Invoice API methods are no longer available.
- You must pass specific subscription details (`subscription`, `subscription_details.items`, `schedule`, `schedule_details.phases`, or `invoice_items`) along with the `customer` parameter to the [Create Preview Invoice API](https://docs.stripe.com/api/invoices/create_preview.md?api-version=2025-03-31.basil).

## Impact

Migrate your integration from `GET /v1/invoices/upcoming` or `GET /v1/invoices/upcoming/lines` API methods to use the [Create Preview Invoice API](https://docs.stripe.com/api/invoices/create_preview.md?api-version=2025-03-31.basil), which offers equivalent functionality and parameters.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2025-03-31.basil`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
