# Makes metadata optional when creating a Batch Job v2

## What’s new

Updates the [metadata](https://docs.stripe.com/api/v2/core/batch-jobs/create.md?api-version=2026-06-24.preview#v2_create_batch_jobs-metadata) parameter to be optional when you [create a Batch Job v2](https://docs.stripe.com/api/v2/core/batch-jobs/create.md?api-version=2026-06-24.preview). Previously, `metadata` was required, meaning every create request had to include it even if you didn’t need to attach any key-value data to the job.

## Impact

You no longer need to include `metadata` in every request to create a Batch Job v2. If you don’t need to attach custom key-value pairs to a job, you can omit the parameter entirely.
