# Adds support for Bizum payments

## What’s new

Adds support for [Bizum](https://docs.stripe.com/payments/bizum.md), a real-time payment method in Spain that allows customers to make instant payments by entering the phone number they’ve registered with Bizum and approving the payment directly in their bank’s app.

## Impact

If your business serves customers in Spain, you can now offer Bizum as a payment option at checkout. Because the payment flow keeps customers on your website throughout the authorisation process, you maintain full control of the checkout flow without depending on external redirects.

When testing in a *sandbox* (A sandbox is an isolated test environment that allows you to test Stripe functionality in your account without affecting your live integration. Use sandboxes to safely experiment with new features and changes), use the [test phone numbers](https://docs.stripe.com/payments/bizum/accept-a-payment.md?payment-ui=checkout#test-integration) to simulate different payment outcomes.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2026-05-27.dahlia`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
