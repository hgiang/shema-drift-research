# Makes status details for Test Clock test helpers required

## What’s new

Adds the required `status_details` hash to test clock resources to record status-related information.

## Impact

Improves the accuracy of [Test Clocks](https://docs.stripe.com/api/test_clocks.md?api-version=2024-09-30.acacia)  by requiring the `status_details` field. This ensures that status-related information is available, allowing you to track and debug test clock activities effectively.

## Changes

#### REST API

| Field | Change | From → to |
| --- | --- | --- |
| `TestHelpers.TestClock.status_details` | Changed | `optional → required` |

#### Ruby

This change doesn’t affect the Ruby SDK.

#### Python

| Fields | Change | From → to |
| --- | --- | --- |
| `status_details`, `stripe.test_helpers.TestClock` | Changed | `Optional[StatusDetails] → StatusDetails` |

#### PHP

This change doesn’t affect the PHP SDK.

#### Java

This change doesn’t affect the Java SDK.

#### Node.js

#### Go

This change doesn’t affect the Go SDK.
