# Adds a new outcome type for rerouted payments to Payment Evaluations

## What’s new

Adds `rerouted` as a new value for the [outcome.type](https://docs.stripe.com/api/radar/payment_evaluations/object.md?api-version=2026-09-30.endive) property for [Payment Evaluations](https://docs.stripe.com/api/radar/payment_evaluations/object.md?api-version=2026-09-30.endive). When a Radar reroute rule fires on a bank payment, Payment Evaluations now return `outcome.type` as `rerouted`.

## Impact

If your integration reads the `outcome.type` property from Payment Evaluations, you now receive the value `rerouted` for applicable Radar rules. Because this is an additive change to an [open enum](https://docs.stripe.com/api/enums.md?api-version=2026-09-30.endive), existing integrations that handle unknown enum values gracefully aren’t affected.
