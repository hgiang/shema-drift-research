# Adds risk requirements to the Capabilities API

## What’s new

Adds [risk requirements](https://docs.stripe.com/connect/handling-api-verification.md?accounts-namespace=v1#handle-risk-verifications) to the [requirements](https://docs.stripe.com/api/capabilities/object.md?api-version=2026-03-25.dahlia#capability_object-requirements) hash of the Capability object.

Previously, risk requirements only appeared in the [requirements](https://docs.stripe.com/api/accounts/object.md?api-version=2026-03-25.dahlia#account_object-requirements) and [future_requirements](https://docs.stripe.com/api/accounts/object.md?api-version=2026-03-25.dahlia#account_object-future_requirements) hashes of the [Account](https://docs.stripe.com/api/accounts/object.md?api-version=2026-03-25.dahlia) object. In the [Accounts v1 API](https://docs.stripe.com/api/accounts.md?api-version=2026-03-25.dahlia), those hashes don’t identify the capabilities that a particular requirement affects.

## Why is this a breaking change?

The Capability object’s `requirements` hash can now contain risk-related requirements. If your integration assumes that it doesn’t include them, you might need to update your code.

## Impact

When using the Accounts v1 API, you can now programmatically identify capabilities that are or can be affected by risk requirements by using the [Capabilities API](https://docs.stripe.com/api/capabilities.md?api-version=2026-03-25.dahlia).

If you use the [Accounts v2 API](https://docs.stripe.com/api/v2/core/accounts.md?api-version=2026-03-25.dahlia), you don’t need to use the Capabilities API. In Accounts v2, each entry in the [requirements](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-03-25.dahlia#v2_account_object-requirements-entries-impact-restricts_capabilities) and [future_requirements](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-03-25.dahlia#v2_account_object-future_requirements-entries-impact-restricts_capabilities) hashes includes an `impact.restricts_capabilities` array listing the capabilities affected by that requirement.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2026-03-25.dahlia`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
