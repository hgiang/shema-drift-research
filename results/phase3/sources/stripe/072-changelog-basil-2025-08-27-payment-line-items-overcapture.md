# Adds support for payment line items with overcapture

## What’s new

You can now add the line items associated with a payment when using [overcapture](https://docs.stripe.com/payments/overcapture.md).

For more information on feature eligibility, restrictions and how to integrate this update, see [payment line items](https://docs.stripe.com/payments/payment-line-items.md).

## Impact

If your integration uses [overcapture](https://docs.stripe.com/payments/overcapture.md), you can now send [payment line items](https://docs.stripe.com/payments/payment-line-items.md) for an overcapture transaction. Sending accurate line item data, including the updated line item breakdowns associated with an overcapture, can provide cost savings, facilitate payment reconciliation and improve auth rates, depending on the payment method.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2025-08-27.preview`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
