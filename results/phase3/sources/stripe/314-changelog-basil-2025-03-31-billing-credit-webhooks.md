# Adds new webhook event types for billing credits

## What’s new

We’re introducing three new event types of webhooks for [Credit Grants](https://docs.stripe.com/api/billing/credit-grant.md?api-version=2025-03-31.basil) and [Credit Balance Transactions](https://docs.stripe.com/api/billing/credit-balance-transaction.md?api-version=2025-03-31.basil):

- `billing.credit_grant.created`: Fires when a Credit Grant is created
- `billing.credit_grant.updated`: Fires when a Credit Grant is updated
- `billing.credit_balance_transaction.created`: Fires when a Credit Balance Transaction is created

## Impact

These new webhook events enable you to:

- Monitor when credit grants are created or updated
- Track credit balance transactions in real-time
- Build automated systems that respond to changes in customer credits
- Receive notifications when credits are granted, voided, expired, applied, or reinstated
- Synchronise customer credit data with your internal systems

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2025-03-31.basil`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
