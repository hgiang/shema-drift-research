# Adds enum values for disabled reasons

## What’s new

Adds `paused.inactivity` and `other` as new disabled reasons in the Capabilities API. To learn more, see [Capability disabled reasons](https://docs.stripe.com/api/accounts/object.md?api-version=2024-06-20#capability_object-requirements-disabled_reason).

## Impact

You now encounter these additional reasons when a capability is disabled, providing more specific information about the cause of the disability.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2024-06-20`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
