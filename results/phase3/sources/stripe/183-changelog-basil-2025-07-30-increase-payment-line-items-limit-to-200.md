# Increases payment line items limit to 200

## What’s new

You can now add up to 200 line items associated with a payment.

For more information on feature eligibility, restrictions, and how to integrate this update, see [Payment line items](https://docs.stripe.com/payments/payment-line-items.md).

## Impact

If your integration uses [payment line items](https://docs.stripe.com/payments/payment-line-items.md), you can now add up to 200 line items.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2025-07-30.preview`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
