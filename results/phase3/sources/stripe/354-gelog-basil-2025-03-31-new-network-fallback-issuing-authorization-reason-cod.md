# Adds reason code for Issuing authorisations created while Stripe is unavailable

## What’s new

Adds `network_fallback` as an option for the [Issuing authorization](https://docs.stripe.com/api/issuing/authorizations/object.md?api-version=2025-03-31.basil) object’s [request_history.reason](https://docs.stripe.com/api/issuing/authorizations/object.md?api-version=2025-03-31.basil#issuing_authorization_object-request_history-reason).

## Why is this a breaking change?

Some users might be expecting a fixed set of options for the [Issuing authorization](https://docs.stripe.com/api/issuing/authorizations/object.md?api-version=2025-03-31.basil) object’s [request_history.reason](https://docs.stripe.com/api/issuing/authorizations/object.md?api-version=2025-03-31.basil#issuing_authorization_object-request_history-reason) property. Update your code to expect this new option.

## Impact

You can now identify Issuing authorisations handled by the network when Stripe is unavailable.
