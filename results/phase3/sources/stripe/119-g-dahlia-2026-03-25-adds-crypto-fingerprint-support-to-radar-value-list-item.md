# Adds crypto fingerprint support to Radar value list items

## What’s new

Adds `crypto_fingerprint` as a new value for the [item_type](https://docs.stripe.com/api/radar/value_lists/create.md?api-version=2026-03-25.dahlia#create_value_list-item_type) parameter when creating a Radar `ValueList`, similar to existing support for `sepa_debit_fingerprint` and `us_bank_account_fingerprint`.

## Impact

You can now write Radar rules on crypto wallet fingerprints to allow trusted wallets or block known fraudulent ones.
