# Expanded availability of Account KYC data

## What’s new

All platforms have read-only access to the following Account fields, regardless of [controller.requirement_collection](https://docs.stripe.com/api/accounts/object.md?api-version=2025-03-31.basil#account_object-controller-requirement_collection) value:

- `business_type`
- `company.name`
- `company.name_kana`
- `company.name_kanji`
- `company.structure`
- `individual.id`
- `individual.object`
- `individual.created`
- `individual.email`
- `individual.first_name`
- `individual.first_name_kana`
- `individual.first_name_kanji`
- `individual.last_name`
- `individual.last_name_kana`
- `individual.last_name_kanji`
- `individual.full_name`
- `individual.full_name_aliases`
- `individual.relationship`
- `person.id`
- `person.object`
- `person.created`
- `person.email`
- `person.first_name`
- `person.first_name_kana`
- `person.first_name_kanji`
- `person.last_name`
- `person.last_name_kana`
- `person.last_name_kanji`
- `person.full_name`
- `person.full_name_aliases`
- `person.relationship`

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2025-03-31.basil`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).

3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
