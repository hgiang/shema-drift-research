# Adds the initCheckout method

## What’s new

Adds the [stripe.initCheckout](https://docs.stripe.com/js/custom_checkout/init) method for creating a checkout page using [Elements with the Checkout Sessions API](https://docs.stripe.com/payments/quickstart.md).

## Impact

The new [stripe.initCheckout](https://docs.stripe.com/js/custom_checkout/init) method lets you [create a custom checkout page using Elements with the Checkout Sessions API](https://docs.stripe.com/payments/quickstart.md). This integration manages tax, discounts, shipping and currency conversion.
