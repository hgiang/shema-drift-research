# Adds support for Global Payouts

## What’s new

Users in the US and UK can now send money directly to third parties using a new set of money management APIs. [Global Payouts](https://docs.stripe.com/global-payouts.md) offers several integration paths with no-code, hosted, and API solutions that allow your business to send and track payouts globally without requiring you to use Stripe for payments.

## Impact

We’ve introduced a new set of money management APIs:

- [Adjustments](https://docs.stripe.com/api/v2/money-management/adjustments.md?api-version=preview) represent Stripe-initiated credits or debits to a user balance.
- [Financial Accounts](https://docs.stripe.com/api/v2/money-management/financial-accounts.md?api-version=preview) are the containers that allow for the configuration of money movement.
- [Financial Addresses](https://docs.stripe.com/api/v2/money-management/financial-addresses.md?api-version=preview) contain information needed to transfer money to a Financial Account.
- [Inbound Transfers](https://docs.stripe.com/api/v2/money-management/inbound-transfers.md?api-version=preview) represent money movement from a user owned PaymentMethod to their FinancialAccount.
- [Outbound Payments](https://docs.stripe.com/api/v2/money-management/outbound-payments.md?api-version=preview) represent money movement from your FinancialAccount to a third party.
- [Outbound Transfers](https://docs.stripe.com/api/v2/money-management/outbound-transfers.md?api-version=preview) represent money movement from your FinancialAccount to yourself.
- [Received Credits](https://docs.stripe.com/api/v2/money-management/received-credits.md?api-version=preview) represent funds sent into your FinancialAccount.
- [Received Debits](https://docs.stripe.com/api/v2/money-management/received-debits.md?api-version=preview) represent funds debited from your FinancialAccount.
- [Transactions](https://docs.stripe.com/api/v2/money-management/transactions.md?api-version=preview) represent changes to your FinancialAccount balance over time.
- [Transaction Entries](https://docs.stripe.com/api/v2/money-management/transaction-entries.md?api-version=preview) represent individual money movements across different states within a Transaction.

Additionally, you can now use [Account Links](https://docs.stripe.com/api/v2/core/account-links.md?api-version=preview) to access the Stripe-hosted Recipient Onboarding application.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2025-04-30.preview`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
