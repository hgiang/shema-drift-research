# Adds presentment details for Adaptive Pricing Subscriptions

## What’s new

Adds a [presentment_details](https://docs.stripe.com/api/subscriptions/object.md?api-version=2026-03-25.dahlia#subscription_object-presentment_details) hash to the Subscription object to provide information about the currency chosen by customers when using Adaptive Pricing.

## Impact

[Adaptive Pricing](https://docs.stripe.com/payments/currencies/localize-prices/adaptive-pricing.md) is now available for Subscriptions, allowing you to offer localised prices to global customers. When a Subscription uses Adaptive Pricing, the new [presentment_details.presentment_currency](https://docs.stripe.com/api/subscriptions/object.md?api-version=2026-03-25.dahlia#subscription_object-presentment_details-presentment_currency) property contains the customer’s chosen currency.
