# Reintroduces the ability to set an amount-off coupon's duration to forever

## What’s new

You can now create amount-off [coupons](https://docs.stripe.com/api/coupons.md?api-version=2026-01-28.clover) or [promotion codes](https://docs.stripe.com/api/promotion_codes.md?api-version=2026-01-28.clover) with `duration=forever` again and apply them to:

- [Subscriptions](https://docs.stripe.com/api/subscriptions.md?api-version=2026-01-28.clover)
- [Subscription Items](https://docs.stripe.com/api/subscription_items.md?api-version=2026-01-28.clover)
- [Subscription Schedules](https://docs.stripe.com/api/subscription_schedules.md?api-version=2026-01-28.clover)
- [Invoices](https://docs.stripe.com/api/invoices.md?api-version=2026-01-28.clover)
- [Invoice Items](https://docs.stripe.com/api/invoiceitems.md?api-version=2026-01-28.clover)
- [Quotes](https://docs.stripe.com/api/quotes.md?api-version=2026-01-28.clover)
- [Checkout Sessions](https://docs.stripe.com/api/checkout/sessions.md?api-version=2026-01-28.clover)

## Impact

Amount-off coupons with `duration=forever` are supported again across all API versions. This restores functionality that was deprecated in [2025-03-31.basil](https://docs.stripe.com/changelog/basil/2025-03-31/restrict-coupon-duration.md).

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2026-01-28.clover`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
