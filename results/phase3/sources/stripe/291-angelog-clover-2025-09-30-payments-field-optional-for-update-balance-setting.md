# Updating Balance Settings no longer requires specifying payment settings

## What’s new

Updating [Balance Settings](https://docs.stripe.com/api/balance-settings/update.md?api-version=2025-09-30.preview) no longer requires inclusion of the [payments](https://docs.stripe.com/api/balance-settings/update.md?api-version=2025-09-30.clover#update_balance_settings-payments) field, which specifies payment settings.

## Impact

You can now exclude the `payments` field when updating [Balance Settings](https://docs.stripe.com/api/balance-settings/update.md?api-version=2025-09-30.preview) if it’s not relevant for your integration.

## Changes

#### REST API

| Field | Change | From → to |
| --- | --- | --- |
| `BalanceSettings#update.payments` | Changed | `required → optional` |

#### Ruby

| Field | Change | From → to |
| --- | --- | --- |
| `BalanceSettings::UpdateParams.payments` | Changed | `required → optional` |

#### Python

| Field | Change | From → to |
| --- | --- | --- |
| `BalanceSettings.ModifyParams.payments` | Changed | `required → optional` |

#### PHP

| Field | Change | From → to |
| --- | --- | --- |
| `BalanceSettings.update().$params.payments` | Changed | `required → optional` |

#### Java

| Field | Change | From → to |
| --- | --- | --- |
| `BalanceSettingsUpdateParams.payments` | Changed | `required → optional` |

#### Node.js

| Field | Change | From → to |
| --- | --- | --- |
| `BalanceSettingUpdateParams.payments` | Changed | `required → optional` |

#### Go

This change doesn’t affect the Go SDK.

#### .NET

This change doesn’t affect the .NET SDK.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2025-09-30.preview`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
