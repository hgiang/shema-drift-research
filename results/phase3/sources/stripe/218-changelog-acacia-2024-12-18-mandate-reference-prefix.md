# Adds support for SEPA Direct Debit and Bacs Direct Debit mandate reference prefix

## What’s new

We added the `reference_prefix` parameter to payment method options for SEPA Direct Debit and Bacs Direct Debit. The parameter is available in [Payment Intents](https://docs.stripe.com/api/payment_intents.md?api-version=2024-12-18.acacia), [Setup Intents](https://docs.stripe.com/api/setup_intents.md?api-version=2024-12-18.acacia) and [Checkout Sessions](https://docs.stripe.com/api/checkout/sessions.md?api-version=2024-12-18.acacia) in Payment and Setup modes.

## Impact

This change lets you specify a reference prefix when creating a mandate with [SEPA Direct Debit](https://docs.stripe.com/api/payment_intents/object.md?api-version=2024-12-18.acacia#payment_intent_object-payment_method_options-sepa_debit-mandate_options-reference_prefix) or [Bacs Direct Debit](https://docs.stripe.com/api/payment_intents/object.md?api-version=2024-12-18.acacia#payment_intent_object-payment_method_options-bacs_debit-mandate_options-reference_prefix).

You can specify a prefix in the `mandate_options.reference_prefix` parameter to customise either the [SEPA Direct Debit Mandate reference](https://docs.stripe.com/api/mandates/object.md?api-version=2024-12-18.acacia#mandate_object-payment_method_details-sepa_debit-reference) or [Bacs Direct Debit Mandate reference](https://docs.stripe.com/api/mandates/object.md?api-version=2024-12-18.acacia#mandate_object-payment_method_details-bacs_debit-reference).
