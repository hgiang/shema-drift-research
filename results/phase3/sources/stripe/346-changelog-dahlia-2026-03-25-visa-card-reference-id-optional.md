# Updates the Issuing Token card reference ID for Visa to be optional

## What’s new

Updates the [network_data.visa.card_reference_id](https://docs.stripe.com/api/issuing/tokens/object.md?api-version=2026-03-25.dahlia#issuing_token_object-network_data-visa-card_reference_id) string property of the [Issuing Token](https://docs.stripe.com/api/issuing/tokens/object.md?api-version=2026-03-25.dahlia) object to be optional. Previously, it couldn’t be null.

## Why is this a breaking change?

Changes the data type of the Issuing Token object’s `network_data.visa.card_reference_id` property from string to nullable string. If your integration accesses this property and assumes that it always has a non-null value, you need to update your code to handle null values.

## Impact

The Issuing Token object now supports tokens from the Visa network that don’t have a reference ID by allowing the reference ID to be null. There is no change to the [network_data.mastercard.card_reference_id](https://docs.stripe.com/api/issuing/tokens/object.md?api-version=2026-03-25.dahlia#issuing_token_object-network_data-mastercard-card_reference_id) property, which already supports null values.
