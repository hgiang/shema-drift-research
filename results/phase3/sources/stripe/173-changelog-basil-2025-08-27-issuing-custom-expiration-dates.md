# Adds support for custom expiry dates to Issuing virtual cards

## What’s new

Adds the ability to specify a custom expiry date using the new `exp_month` and `exp_year` parameters when [creating an Issuing virtual card using the API](https://docs.stripe.com/issuing/cards/virtual/issue-cards.md?testing-method=with-code#exp-dates).

## Impact

You can now specify a custom expiry date when creating an Issuing virtual card using the API. A custom expiry date must be at least one month in the future and less than five years in the future.
