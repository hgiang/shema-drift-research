# Makes Accounts v2 available to all Stripe users for managing customers

## What’s new

The [Accounts v2 API](https://docs.stripe.com/api/v2/core/accounts.md?api-version=2026-04-22.preview) is now available in public preview for all Stripe users, extending its availability beyond Connect platforms.

You can use [/v2/core/accounts](https://docs.stripe.com/api/v2/core/accounts.md?api-version=2026-04-22.preview) with the `customer` configuration to represent customers using [Account](https://docs.stripe.com/api/v2/core/accounts.md?api-version=2026-04-22.preview) objects. After you [enable the preview](https://docs.stripe.com/accounts-v2/use-accounts-as-customers.md), Stripe automatically makes your existing [Customer](https://docs.stripe.com/api/customers/object.md?api-version=2026-04-22.preview) objects available as [Account](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-04-22.preview) objects with the `customer` configuration and keeps newly created `Accounts` or `Customer` objects interoperable.

After opting in, new customers created in the Dashboard and through Stripe-hosted checkout flows create customer-configured `Account` objects instead of `Customer` objects.

Learn more about [representing customers using Account objects](https://docs.stripe.com/accounts-v2/use-accounts-as-customers.md).

## Impact

This change affects merchants who want to use [Accounts v2](https://docs.stripe.com/api/v2/core/accounts.md?api-version=2026-04-22.preview) to represent customers, and Connect platforms who want to sync existing [Customer](https://docs.stripe.com/api/customers/object.md?api-version=2026-04-22.preview) objects with [Account v2](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-04-22.preview) objects.

You can continue using the [Customers API](https://docs.stripe.com/api/customers.md?api-version=2026-04-22.preview), since Stripe maintains interoperability between synced [Customer](https://docs.stripe.com/api/customers/object.md?api-version=2026-04-22.preview) and [Account v2](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-04-22.preview) objects. Supported v1 APIs accept `customer_account` in addition to `customer`.

Opting out stops new automatic syncing, but doesn’t undo changes to existing `Customer` objects that are already associated with `Account` objects. Some customer features remain unsupported in preview. See the preview guide [for current limitations and opt-out behaviour](https://docs.stripe.com/accounts-v2/use-accounts-as-customers.md#limitations-and-opting-out).

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2026-04-22.preview`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
