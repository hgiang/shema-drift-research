# Modify phone number collection on Payment Links

## What’s new

Adds the [phone_number_collection](https://docs.stripe.com/api/payment-link/object.md?api-version=2025-01-27.acacia#payment_link_object-phone_number_collection) parameter to the [update Payment Link method](https://docs.stripe.com/api/payment-link/update.md?api-version=2025-01-27.acacia). You can use this new parameter to enable or disable phone number collection in the payment form of an existing Payment Link.

## Impact

You can now update existing Payment Links to configure whether the payment form requires the customer to provide a phone number. Previously, you had to set this configuration when creating a Payment Link, with no way to change it.
