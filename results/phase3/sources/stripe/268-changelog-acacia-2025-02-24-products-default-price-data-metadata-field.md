# Adds metadata field to the Products API for creating an inline default price

## What’s new

Adds a [metadata](https://docs.stripe.com/api/products/create.md?api-version=2025-02-24.acacia#create_product-default_price_data-metadata) parameter to the [Create a product](https://docs.stripe.com/api/products/create.md?api-version=2025-02-24.acacia) method.

## Impact

You can add `metadata` fields to prices when you [create products](https://docs.stripe.com/api/products/create.md?api-version=2025-02-24.acacia). Previously, you had to make a separate API call to update the [Price](https://docs.stripe.com/api/prices.md?api-version=2025-02-24.acacia) object after creating the Product.
