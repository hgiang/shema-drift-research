# Adds rejected status for Accounts v2 capabilities

## What’s new

Adds a `rejected` value to the [status](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-09-30.endive#v2_core_account_object-merchant) property of account capabilities on [Accounts v2](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-09-30.endive). This status appears alongside the existing values `active`, `pending`, `restricted` and `unsupported`.

The [status_details](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-09-30.endive#v2_core_account_object-merchant) property now provides specific codes that describe the reason for rejection:

- `rejected_fraud`
- `rejected_incomplete_verification`
- `rejected_listed`
- `rejected_other`
- `rejected_platform_fraud`
- `rejected_platform_other`
- `rejected_platform_terms_of_service`
- `rejected_terms_of_service`

These codes can appear in the capability status for [merchant](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-09-30.endive#v2_core_account_object-merchant), [recipient](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-09-30.endive#v2_core_account_object-recipient) and [storer](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-09-30.endive#v2_core_account_object-storer) configurations.

For rejected accounts, API versions before `2026-09-30.endive` return:

- `restricted` instead of `rejected` for `status`
- `restricted_other` instead of a specific `rejected_*` code in `status_details`

## Why is this a breaking change?

Previously, rejected accounts provided a `status` of `restricted` with a `status_details` code of `requirements_past_due`.

When an account is rejected, we now return more specific error codes that describe the rejection reason. If your integration uses the `restricted` status to identify rejected accounts, you must update your code to handle the `rejected` status and the associated detail codes.

## Impact

If your integration reads capability `status` or `status_details` values from Accounts v2 [Account](https://docs.stripe.com/api/v2/core/accounts/object.md?api-version=2026-09-30.endive) objects, you can now understand and handle the specific reasons a capability configuration was rejected.

These events also now include the `rejected` status for rejected accounts:

- [v2.core.account[configuration.merchant].capability_status_updated](https://docs.stripe.com/api/v2/core/accounts/event-types.md?api-version=2026-09-30.endive#v2_accounts_event_types-v2.core.account%5Bconfiguration.merchant%5D.capability_status_updated)

- [v2.core.account[configuration.recipient].capability_status_updated](https://docs.stripe.com/api/v2/core/accounts/event-types.md?api-version=2026-09-30.endive#v2_accounts_event_types-v2.core.account%5Bconfiguration.recipient%5D.capability_status_updated)
