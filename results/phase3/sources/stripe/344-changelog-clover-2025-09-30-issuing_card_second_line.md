# Adds support for printing a second line on Issuing physical cards

## What’s new

When creating an [Issuing Card](https://docs.stripe.com/api/issuing/cards.md?api-version=2025-09-30.clover) object, you can now specify a second line to print on physical cards using the new [second_line](https://docs.stripe.com/api/issuing/cards/object.md?api-version=2025-09-30.clover#issuing_card_object-second_line) parameter.

## Impact

You can now specify the text to print on physical cards that use a [Physical Bundle](https://docs.stripe.com/api/issuing/physical_bundles.md?api-version=2025-09-30.clover) that permits a second line. The second line appears beneath the cardholder name, and can convey additional information to the cardholder about the card.
