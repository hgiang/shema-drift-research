# Billing Portal Configuration always returns period end date in responses

## What’s new

The [Customer Portal Configuration API](https://docs.stripe.com/api/customer_portal/configurations.md?api-version=2024-12-18.acacia) now always includes the [schedule_at_period_end](https://docs.stripe.com/api/customer_portal/configurations/update.md?api-version=2024-12-18.acacia#update_portal_configuration-features-subscription_update-schedule_at_period_end) property in API responses. This means that you don’t have to handle null values in responses.

## Changes

#### REST API

| Field | Change | From → to |
| --- | --- | --- |
| `BillingPortal.Configuration.features.subscription_update.schedule_at_period_end` | Changed | `optional → required` |
