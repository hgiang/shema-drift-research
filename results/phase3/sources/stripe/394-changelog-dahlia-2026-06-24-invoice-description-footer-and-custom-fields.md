# Adds invoice description, footer and custom fields to the Subscriptions API

## What’s new

The [description](https://docs.stripe.com/api/subscriptions/create.md?api-version=2026-06-24.dahlia#create_subscription-invoice_settings-description), [footer](https://docs.stripe.com/api/subscriptions/create.md?api-version=2026-06-24.dahlia#create_subscription-invoice_settings-footer), and [custom_fields](https://docs.stripe.com/api/subscriptions/create.md?api-version=2026-06-24.dahlia#create_subscription-invoice_settings-custom_fields) parameters are now available on the [invoice_settings](https://docs.stripe.com/api/subscriptions/create.md?api-version=2026-06-24.dahlia#create_subscription-invoice_settings) hash when you create or update a [Subscription](https://docs.stripe.com/api/subscriptions.md?api-version=2026-06-24.dahlia). These properties are also returned when you retrieve a Subscription. Previously, these fields were configurable exclusively in the Stripe Dashboard.

## Impact

You can now programmatically control the description, footer and custom fields that appear on every invoice generated by a subscription without needing to update each invoice individually. This is useful for adding information such as PO numbers, contract references, or other reconciliation details at the subscription level. See the [subscription invoices documentation](https://docs.stripe.com/billing/invoices/subscription.md) for more details.

2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2026-06-24.dahlia`

4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
