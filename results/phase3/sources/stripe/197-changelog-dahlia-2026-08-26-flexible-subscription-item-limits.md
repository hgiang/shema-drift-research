# Increases the subscription item limit

## What’s new

Raises the subscription item limit from 20 to 100 for [flexible billing mode](https://docs.stripe.com/billing/subscriptions/billing-mode.md) [subscriptions](https://docs.stripe.com/api/subscriptions/object.md?api-version=2026-08-26.dahlia#subscription_object-items) and [subscription schedules](https://docs.stripe.com/api/subscription_schedules/object.md?api-version=2026-08-26.dahlia#subscription_schedule_object-phases-items). This change applies to all API versions.

## Impact

You can now add up to 100 items when creating or updating subscriptions set to flexible billing mode. Existing integrations require no changes unless you need more than 20 items.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2026-08-26.dahlia`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
