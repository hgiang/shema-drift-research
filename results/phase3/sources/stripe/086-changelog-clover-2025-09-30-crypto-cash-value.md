# Adds cash as a value for the crypto token currency enum

## What’s new

Adds `cash` as a value for the [crypto.token_currency](https://docs.stripe.com/api/charges/object.md?api-version=2025-09-30.clover#charge_object-payment_method_details-crypto-token_currency) enum when using [Charges](https://docs.stripe.com/api/charges.md?api-version=2025-09-30.clover).

## Impact

You can now see whether a Charge used the `cash` value for the [token_currency](https://docs.stripe.com/api/charges/object.md?api-version=2025-09-30.clover#charge_object-payment_method_details-crypto-token_currency) enum.
