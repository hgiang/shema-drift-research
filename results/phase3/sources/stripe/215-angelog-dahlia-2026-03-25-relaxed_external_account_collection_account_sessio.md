# Removes the requirement for certain connected accounts to collect external account information in the Account Sessions API

## What’s new

Adds the ability for [Connect embedded components](https://docs.stripe.com/connect/supported-embedded-components/account-onboarding.md) to skip collecting external account information when [Stripe is responsible for collecting requirements](https://docs.stripe.com/connect/accounts-v2/connected-account-configuration.md#kyc-requirements) and Stripe user authentication is enabled. Previously, Connect embedded components always required external account information when Stripe was responsible for collecting requirements, regardless of whether Stripe authentication was enabled.

## Impact

Previously, when calling the Account Sessions API, you could set [components.account_onboarding.features.external_account_collection](https://docs.stripe.com/api/account_sessions/object.md?api-version=2026-02-25.preview#account_session_object-components-account_onboarding-features-external_account_collection) to false only if [the platform was responsible for collecting requirements](https://docs.stripe.com/connect/accounts-v2/connected-account-configuration.md#kyc-requirements). Now, if Stripe is responsible for collecting requirements, you can set `external_account_collection` to false if you also set [components.account_onboarding.features.disable_stripe_user_authentication](https://docs.stripe.com/api/account_sessions/object.md?api-version=2026-02-25.preview#account_session_object-components-account_onboarding-features-disable_stripe_user_authentication) to false. Read more about [external account collection with Connect embedded components](https://docs.stripe.com/connect/supported-embedded-components/account-onboarding.md#external-account-collection).

The default value of `external_account_collection` is still true.

## Upgrade

#### REST API

1. [View your current API version](https://docs.stripe.com/workbench/guides.md#view-api-versions) in Workbench.
2. If you use an SDK, upgrade to the corresponding SDK version for this API version.
   - If you don’t use an SDK, update your [API requests](https://docs.stripe.com/api-versions.md#how-versions-are-specified-in-requests) to include `Stripe-Version: 2026-03-25.dahlia`
3. Upgrade the API version used for [webhook endpoints](https://docs.stripe.com/webhooks/versioning.md).
4. [Test your integration](https://docs.stripe.com/testing.md) against the new version.
5. If you use Connect, [test your Connect integration](https://docs.stripe.com/connect/testing.md).

Learn more about [Stripe API upgrades](https://docs.stripe.com/upgrades.md).
